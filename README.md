# Flux-Activated Resonant Control of a Bosonic Quantum Memory
This repository accompanies the manuscript “Flux-Activated Resonant Control of a Bosonic Quantum Memory” and contains the experimental datasets, numerical simulation scripts, and data analysis routines used in the study, including implementations of quantum state reconstruction and Bayesian inference.
